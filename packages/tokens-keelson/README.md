# @keelson/tokens

Design tokens for Keelson (plan §12): calm, cool-neutral surfaces, a teal accent, rounded
shapes and a pill composer. No Google branding — Gemini-like *behaviour* only.

| File | What |
|---|---|
| `src/palette.ts` | **Single source of truth** (OKLCH colours per theme, radii, type scale, durations, easings, shadows, layout, Motion springs). |
| `src/tokens.css` | *Generated.* CSS variables `--k-*` for `:root`/`[data-theme="light"]` and `[data-theme="dark"]`, plus sRGB hex fallbacks under `@supports not (color: oklch(0 0 0))`. |
| `src/theme.css` | Tailwind 4 mapping: `@theme inline` colours → `var(--k-*)`, radii, type scale (`text-display/title/heading/body/ui/caption`), `--font-sans: "Inter Variable"`, `max-w-chat` (760 px), `animate-shimmer`/`animate-pulse-soft`, `@custom-variant dark (&:where([data-theme=dark], [data-theme=dark] *))`, base layer (focus ring, reduced-motion). Imports `tokens.css`. |
| `src/generated/hex.ts` | *Generated.* Gamut-mapped hex for every colour role (culori), for ECharts / deck.gl / canvas. |
| `src/index.ts` | `tokens`, `hex`, `hexColor`, `rgba`, `chartPalette`, `cssVar`, `stageOrder`, `stageLabels`, `stagePhases`, `provenanceMeta`, `severityMeta`, `springs`. |

## Use (app)

```css
/* apps/keelson-web/app/globals.css */
@import "tailwindcss";
@import "@keelson/tokens/theme.css";
@import "@keelson/ui/styles.css";
@import "@keelson/viz/styles.css";
```

```ts
import "@fontsource-variable/inter"; // the app ships the font, not this package
import { hexColor, chartPalette, stageLabels, springs } from "@keelson/tokens";
```

Dark mode: set `data-theme="dark"` on `<html>` (the app decides; e.g. from
`prefers-color-scheme` or a user toggle). Utilities such as `bg-surface`, `text-fg-muted`,
`border-prov-simulated`, `rounded-pill`, `text-ui` are generated by Tailwind from `theme.css`.

Colour roles: surfaces `bg, surface, surface-2, surface-3, border, border-strong, scrim`; text
`fg, fg-muted, fg-subtle, fg-inverse`; accent `accent, accent-hover, accent-fg, accent-soft,
accent-soft-fg, focus`; status `danger|warning|success|info (+ -soft)`; thinking sweep
`sweep-1..3` (teal → green → amber); provenance `prov-<kind>` and `prov-<kind>-soft` for
fact / inference / assumption / simulated / decision / committed / verified; severity
`sev-info|low|medium|high|critical` (separate scale); charts `chart-1..6`.

## Regenerate / check

```bash
S=… # see 60-build-guide: node:24-slim, node_modules in a named volume
pnpm --filter @keelson/tokens generate   # writes src/tokens.css + src/generated/hex.ts
pnpm --filter @keelson/tokens build      # --check: fails when the generated files are stale
pnpm --filter @keelson/tokens test       # sync check + WCAG AA contrast pairs (light & dark)
```

Tests assert WCAG 2.2 AA contrast (4.5:1) for every text/background pair used by the UI
(fg on surfaces, muted text, accent text, accent-fg on accent, each provenance colour on its
soft background, status colours) in both themes.
