# 25 · Canonical supply-network model `scn/1.0` (exchange format)

Used by Tier-B connectors (Merxa exports it natively) and by the Keelson sync worker (M3). Parquet (pyarrow, zstd), one dataset per entity, ≤50k rows/part. Conventions: integers for quantities (eaches) and money (minor units, `currency` column where relevant), ISO dates (`date32`), ISO weeks as `YYYY-Www` strings, timestamps UTC. Every row has `source_id` (stable key in the source system) and `src_version` (int ETag, 0 if not versioned).

| entity | columns |
|---|---|
| `location` | source_id, kind {dc,store,cluster,port,factory,supplier,airport}, code, name, country, city, lat (float64), lon (float64), parent_code (store→cluster, cluster→dc, factory→supplier), grade, climate, unlocode, src_version |
| `item` | source_id, kind {sku,style,component}, code, style_code, family, colour, size, size_seq, retail_price_cents, unit_cost_cents, currency, src_version |
| `bom_line` | source_id, style_code, component_code, supplier_code, factory_code (nullable = all), qty_per_unit, src_version |
| `lane` | source_id, code, origin_code, dest_code, mode {sea,air,sea_air,road}, carrier_code, transit_days, via (list<string>), alt_lane_code, src_version |
| `lane_rate` | source_id, lane_code, valid_from, valid_to, basis, rate_cents, weekly_capacity, src_version |
| `sailing` | source_id, code, lane_code, cutoff, etd, eta, capacity_teu, status, src_version |
| `po_line` | source_id (`<po>#<line>`), po_code, line_no, supplier_code, factory_code, dest_dc_code, sku_code, qty_ordered, qty_received, ex_factory_date, eta_dc, status, shipment_code, sailing_code, src_version |
| `production_order` | source_id, code, po_line_ref, line_code, seq, planned_start, planned_end, status, hold_reason, src_version |
| `inventory_position` | source_id, location_kind {dc,store}, location_code, sku_code, on_hand, allocated, reserved, in_transit, src_version |
| `demand_forecast` | source_id, style_code, location_kind {store,cluster}, location_code, iso_week, units, forecast_version |
| `size_curve` | source_id, family, cluster_code, size, share_bp |
| `allocation` | source_id, code, sku_code, dc_code, store_code, ship_week, qty, status, src_version |
| `transfer_order_line` | source_id, to_code, from_dc, to_dc, ship_date, eta_date, sku_code, qty, status, src_version |
| `online_order_line` | source_id, order_code, market, channel, store_code, sku_code, qty, reserved_qty, promise_date, status, src_version |
| `promotion` | source_id, code, markets (list), grades (list), style_codes (list), period_start, period_end, discount_bp, uplift_bp, src_version |

Snapshot manifest (returned by `scn.snapshot_open`) carries `canonical_model: "scn/1.0"`, row counts and per-part sha256. Consumers verify counts and hashes before loading. Merxa's mapping to `scn/1.0` is the identity (column names above); other vendors map via a per-connector YAML (M7+).
